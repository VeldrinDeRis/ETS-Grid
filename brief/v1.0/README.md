# ETS GRID — пакет ТЗ на сайт-магазин (v1.0, 13.10.2026)

Сайт-магазин: зарядные станции, солнечные панели, батареи, Solar Carport + доставка, монтаж, сервис.

## Что внутри
| Файл | Для кого | Что это |
|---|---|---|
| `01_TZ_ETS-GRID_sait-magazin.md` / `.docx` | дизайн-студия, заказчик | Техническое задание: цели, уровни, страницы, продающий первый экран, фильтры, дизайн, функции, техника, этапы, приёмка |
| `02_INSTRUKTSIYA_dlya_agenta.md` | AI-агент-исполнитель | Пошаговая инструкция: правила, стек, структура проекта, план, Definition of Done |
| `03_struktura_i_filtry.md` | студия, разработчик, агент | Спецификация: карта URL, конфиг фильтров (JSON), формулы подборщиков и конфигуратора |
| `04_FOTO_istochniki.md` | дизайнер, агент | Где брать фото (можно чужие), правила для продакшена, shot list, учёт источников |
| `data/catalog-sample.json` | разработчик, агент | Демо-каталог: 19 товаров по 4 уровням + 4 готовые системы |
| `refs/` | все | 3 HTML-макета заказчика + бриф и концепция студии |

## Порядок чтения
- **Студия:** 01 → 03 → 04 → refs.
- **Агент:** 02 (там свой порядок чтения).

## Как передать агенту
Распакуйте архив в пустую папку и дайте агенту задание:
> Прочитай `02_INSTRUKTSIYA_dlya_agenta.md` в этой папке и выполни её полностью. Результат — папка `ets-grid-site/` и архив `ets-grid-site.zip`.
