# ETS GRID — бриф студии (v0.1, 2026-10-09)

Документ студии: что известно о клиенте и задаче, какие решения уже приняты, какие допущения мы делаем, что спросить у клиента. Источники: работа в этом проекте (ADR-0053…0054, макеты А/Б, испытание скиллов, разбор макета `STYLE.md`).

## 1. Клиент и продукт
- **ETS GRID**, Киев. Продажа, монтаж и сервис: зарядные станции для электромобилей (AC 7–22 кВт для дома и бизнеса; DC 60–240 кВт для АЗС, автопарков, ТЦ), солнечные электростанции, накопители энергии (BESS) — от домашних 5–10 кВт·год до промышленных 215–400 кВт·год.
- Модель продаж смешанная: мелкие позиции (домашние станции, кабели, адаптеры, панели, инверторы) — покупка онлайн; DC, СЭС, промышленные BESS — расчёт и КП, монтаж под ключ.
- Аудитории: владелец электромобиля / дома; бизнес (паркинг, отель, офис, ТЦ); автопарки и АЗС.

## 2. Задача
Сайт-магазин и генератор заявок, который **заметно выделяется** на рынке и при этом продаёт: быстрый, понятный на телефоне, находимый в Google.

## 3. Уже принятые решения (не обсуждаются заново)
| Решение | Источник |
|---|---|
| Язык — украинский, версия по умолчанию; русской версии нет | ADR-0054 |
| Цены в гривнах, «від» для позиций под расчёт | разбор макета, закон о защите прав потребителей — проверить с юристом |
| Весь контент — в HTML от сервера; анимация только поверх | проверка тестовых страниц: каталог не виден без JS |
| Проектирование от телефона (375/320 px), отдельное поведение ключевых блоков, а не «сжатие в колонку» | мобильный разбор макета |
| Расчёт мощности учитывает «вход от N кВт» станции и ёмкость накопителя в кВт·год | ошибка в макете: 60 кВт сети ≠ достаточно для DC 60 |
| Украинская типографика: «», —, ʼ, `кВт·год`, неразрывные пробелы | ADR-0054 |
| Не использовать «вкус по умолчанию» моделей: Unbounded + моно + лайм на графите | три независимых макета сошлись в одну эстетику |

## 4. Допущения студии (до ответа клиента)
- Брендбука нет: логотип и фирменный цвет разрабатываем в рамках проекта (направление, не финальный логотип).
- Фото реальных объектов нет: в прототипе — иллюстрации/рендеры; в продакшене — съёмка 3–5 объектов (бюджетная статья).
- Каталог на старте: ~30–60 SKU; CMS нужна менеджеру без разработчика.
- Основная конверсия — заявка на расчёт (телефон / Telegram / Viber), вторичная — покупка мелочей.

## 5. Вопросы клиенту (discovery)
1. Есть ли логотип, цвета, фото объектов, сертификаты, реальные кейсы с цифрами?
2. Какие бренды/производители станций и панелей вы продаёте (или это своя марка ETS)?
3. Кто основной клиент по выручке: дом, бизнес или АЗС/автопарки?
4. Какая доля продаж онлайн-оплатой, какая — через КП? Нужна ли корзина на старте?
5. Есть ли CRM, телефония, менеджеры, которые принимают заявки? Какие каналы: телефон, Telegram, Viber?
6. Финансирование: кредит, лизинг, государственные или грантовые программы — работаете ли вы с ними?
7. География монтажа: Киев и область или вся Украина?
8. Бюджет и срок запуска; нужна ли английская версия для иностранных доноров/партнёров?
