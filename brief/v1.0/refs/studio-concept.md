# ETS GRID — концепция сайта (студия, v1.0, 2026-10-09)

Основание: `research/01-awards.md`, `02-market-ua.md`, `03-tech.md`, `04-github.md`, `05-internal-kb.md`, бриф `00-brief.md`.

## 1. Инсайт
Украинский покупатель энергооборудования покупает не киловатты, а **часы со светом и километры в день**. Зима 2025/26 — самая тяжёлая по отключениям; при этом весь рынок говорит характеристиками: «10 кВт·год», «CCS2», «IP55». Конкуренты делятся на два лагеря — «каталог железа без монтажа» и «заявка без цены» — и продают зарядки, солнце и накопители раздельно (`02-market-ua.md`).

## 2. Большая идея
### «Світло лишається» — енергія, яка не вимикається
ETS GRID — не магазин железа, а **интегратор одной энергосистемы**: зарядка + сонце + накопичувач. Сайт говорит результатом: «ваш дім протримається 14 год без мережі», «парковка зарядить 18 авто на день», «100 км — 40 грн замість 450».

Сквозной образ — **освещённое окно в тёмном доме** во время отключения: самый узнаваемый образ украинских зим, и точный ответ на него. Он же — фирменный знак (светящийся прямоугольник-«окно» в логотипе), он же — индикатор состояния во всех интерактивных блоках: окно светится, пока энергии хватает.

| Тон | спокойная уверенность инженера: коротко, по-человечески, без превосходных степеней |

## 4. Фирменные взаимодействия (то, за что сайт запомнят)
1. **«Світломір»** — персональная цифра в первом экране. Выбор: квартира / дім / бізнес; что должно работать (світло й інтернет, холодильник, котел і насос, заряджати авто). Ответ: «≈ 14 год світла» + силуэт дома, в котором окна загораются по мере роста часов. Лёгкая SVG + 2 КБ логики; без JS — таблица типовых сценариев.
2. **«Доба з ETS GRID»** — 24-часовая лента, которую пользователь сам прокручивает пальцем (не скроллджекинг): рассвет → панели заряжают батарею → днём заряжается авто → 18:00 отключение по графику → дом светится от батареи → ночной тариф. Одна SVG-схема потоков энергии, состояния меняются по ползунку времени.
3. **«Перевірка вводу»** — первый шаг для зарядок: фазы и выделенная мощность → сценарий («7 кВт без техумов», «22 кВт + балансування», «DC 60 потребує від 65 кВт — або накопичувач»). Расчёт учитывает «вхід від N кВт» и ёмкость в кВт·год.
4. **«Сумісність з авто»** — модель авто → разъёмы AC/DC, реальная скорость, отдельный путь для GB/T (авто из Китая). Ниша, которую никто не закрывает.

Всё четыре — формы и SVG, работают на 3G и с выключенным JS (контент и типовые ответы в HTML).

## 5. Направление бренда (до разработки логотипа)
- **Цвет.** Ночь: глубокий синий-графит `#0D1424` и «тёплый свет окна» `#FFB547` как единственный акцент (только заливка под тёмным текстом или текст на тёмном). День: светлый холодный `#F4F6F8`, текст `#0D1424`. Отказ от лайма и неона — это «вкус по умолчанию» AI-сайтов.
- **Шрифт.** Украинская гарнитура с полной кириллицей (ґ, ʼ) и характером — финальный выбор по `04-github.md`; не тройка Unbounded/Golos/JetBrains Mono.
- **Графика.** Простые архитектурные силуэты, линии энергии, окна. Фото — только реальные объекты клиента (съёмка в продакшене).
- **Движение.** Свет «включается», а не «вылетает»: плавное нарастание яркости 300–600 мс, линии энергии текут; ничего не прыгает. Только `transform`/`opacity`, `prefers-reduced-motion` — всё статично.

## 6. Структура сайта
| Раздел | Задача | Ключевые блоки |
|---|---|---|
| Головна | показать результат и развести аудитории | Світломір, Доба з ETS GRID, 3 входа (Дім / Бізнес / АЗС і автопарки), пакети, об'єкти, сервісний стандарт |
| Дім | продать пакет | пакети з повною ціною під ключ, сумісність з авто, фінансування (кредит 0 %, компенсація) |
| Бізнес | заявка на расчёт | перевірка вводу, дохід від станцій, навес із панелями, білінг/RFID/OCPP |
| АЗС і автопарки | заявка на расчёт | DC + накопичувач проти пікових навантажень, чесна структура ціни, строки |
| Магазин | купить мелочь / выбрать станцию | каталог в HTML, фильтры, AC — «До кошика», DC — «Розрахувати» |
| Фінансування | снять барьер цены | навигатор программ с датой проверки условий |
| Сервіс | доверие | SLA, моніторинг, зимовий чек-ап |
| Об'єкти | доказательства | карта, кейсы «під час відключення» |

## 7. Метрики успеха
- Конверсия в заявку с главной и страниц сегментов; доля заявок с заполненным «техзаданием» из Світломіра / Перевірки вводу.
- CWV (p75, поле): LCP ≤ 2,0 с, INP ≤ 150 мс, CLS ≤ 0,05; Lighthouse mobile ≥ 90 / A11y ≥ 95 / SEO = 100.
- Органика по кластерам «зарядна станція для дому», «сонячна станція під ключ», «накопичувач для дому», «GB/T зарядка».

## 8. Чего не делаем (и почему)
Скроллджекинг, полноэкранный WebGL-мир, 3D/360 вместо фото и характеристик, корзина для DC-станций, выдуманные цифры и логотипы клиентов (`01-awards.md`, `03-tech.md`).
