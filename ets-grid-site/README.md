# ETS GRID — кликабельный мокап сайта-магазина

Astro 7 + TypeScript + CSS-токены, острова Preact 10, статическая сборка. Порядок работы: спецификация → утверждение → тесты → код ([specs/](../specs/), D-022…D-024).

## Запуск

```bash
npm i
npm run dev        # разработка: http://localhost:4321/
npm run build      # astro check + сборка в dist/
npm run serve      # собранный сайт: http://localhost:4321/
npm run release    # releases/ets-grid-site-ГГГГ-ММ-ДД.zip для заказчика
```

**Motion+ (D-043).** Пакет `@motionplus/core` ставится из закрытого реестра: перед `npm i` задать переменную среды `MOTION_TOKEN` (токен участника Motion+). Без токена `npm i` не пройдёт; собранному сайту токен не нужен.

**Показ из архива (D-019).** Распаковать zip, открыть `site/start.cmd` двойным кликом: поднимется локальный сервер и откроется браузер. Нужен Node.js 22+, интернет не нужен. В `source/` — исходники без `node_modules`.

## Тесты (D-024)

```bash
npm test           # unit + data, секунды
npm run test:all   # сборка + все категории, перед слиянием в main
```

Категории, команды и покрытие критериев — [tests/README.md](tests/README.md).

## Что заглушено
- Содержимое страниц, кроме названия товара и цены, — по спецификациям SPEC-002…009.
- Аналитика: `track()` пишет в `console.debug` (`src/lib/track.ts`).
- Домен — `https://ets-grid.test` (Q-7).
- Шрифты — системные до раунда дизайна; значения токенов, кроме опорных цветов ТЗ, временные.

## Що надає замовник
Видимі плейсхолдери на сайті: `[ТЕЛЕФОН]`, `[EMAIL]`, `[АДРЕСА]`, `[TELEGRAM]`, `[VIBER]`, `[РЕКВІЗИТИ]` (`src/data/structure.json`); у каталозі — `[БРЕНД]`, `[КРАЇНА]`, `[N] роки`, `[ЄМНІСТЬ]`, `[ДЖЕРЕЛО]`, `[N]` у результатах систем (`src/data/catalog.json`). Також: логотип, тексти документів, реальні обʼєкти, домен.
