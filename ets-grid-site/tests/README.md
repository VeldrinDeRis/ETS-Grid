# Библиотека тестов

Правило (D-023): каждый критерий приёмки `SPEC-0NN/AC-NN` из [specs/](../../specs/) становится тестом с этим номером в названии.

| Папка | Чем | Что проверяет |
|---|---|---|
| `unit/` | Vitest | формулы подборщиков и Carport, логика фильтров, корзина, форматирование |
| `data/` | Vitest + Zod | каталог по схеме, целостность ссылок, у каждого листинга есть выдача или экран «підберемо» |
| `e2e/` | Playwright, 375 и 1440 | сценарии ТЗ §7, страницы без JS, доступность (axe-core); визуальные эталоны — после утверждения дизайна |
| `fixtures/` | — | тестовые данные отдельно от `src/data/catalog.json` |

Lighthouse — через MCP Chrome DevTools, отчёты в `../qa/`.

Правила: тест логики пишется до кода; тест интерфейса — вместе с кодом; баг → сначала воспроизводящий тест; в `main` сливается только при зелёном полном прогоне.

Команды появятся в SPEC-001.
