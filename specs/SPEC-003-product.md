## 1. Цель
На странице товара покупатель понимает, что он получит под ключ и за сколько, подходит ли товар его авто и его вводу, что добавить к системе, — и кладёт в корзину или просит расчёт. Двигает конверсию ТЗ §2 и сценарий «главная → подборщик → карточка → з монтажем → корзина» (ТЗ §7, §14: ≤ 6 шагов).

## 2. Источники
- ТЗ §6.4 (11 пунктов карточки), §5 (обязательные перекрёстные блоки), §6.3 (кнопки по `sale_mode`), §8.3 (фото 1:1 или 4:5 на светлом фоне), §9.6 (`docs[]`, `related[]`, `cross_level[]`), §10.1 (доставка, оплата, недавно просмотренные).
- `03_struktura_i_filtry.md` §4 — обязательные характеристики по уровням.
- `04_FOTO_istochniki.md` — кадры и учёт фото.
- Решения: D-005, D-027 (`cars.json`, `quoteFor`), D-029, D-031 (ничего не скрываем).

### 3.2. Состав «з монтажем» (`src/data/product-content.json`)
По уровням, без цифр-фактов: зарядки — «кабель до [N] м, автомат, ПЗВ, монтаж, пусконалагодження»; панели, инверторы — «кріплення, монтаж, підключення, запуск»; батареи — «монтаж, підключення до інвертора, налаштування»; СЕС и Carport — «проєкт, обладнання, монтаж, запуск». Цена монтажа = `price_turnkey_from − price_equipment` (показывается «монтаж від … ₴»), только когда есть обе цены.

### 3.3. Совместимость с авто (`src/lib/product.ts` → `carCompatibility(product, car)`)
| Ситуация | Результат |
|---|---|
| разъём авто AC есть у станции (AC) | «Підходить», скорость = `min(power_kw станції, ac_max_kw авто)` |
| разъём авто DC есть у станции (DC) | «Підходить», скорость = `min(power_kw, dc_max_kw)` |
| авто с GB/T AC, станция с Type 2, в каталоге есть адаптер Type 2 → GB/T AC | «Потрібен адаптер» + карточка адаптера; скорость как для AC |
| иначе | «Не підходить» + ссылка на фильтр «Підбір за авто» в листинге |
| у авто нет мощности (`null`) | скорость не показывается, текст «швидкість уточнимо» |

### 3.4. Недавно просмотренные и аналитика
- При открытии страницы slug пишется в начало `etsgrid:recent:v1` (без дублей, до 8).
- События: `add_to_cart` (с `turnkey`), `compare_add`, клик «Розрахувати» — по атрибуту для `quote_submit` воронки (SPEC-009).

### 3.5. Товар в языке витрины (ревизия 1, D-071)
**Осмотр 15.10** (`research/shop-review/product-*.png`): страница товара — 5 500 px на 1440 и 7 100 px на 375, одиннадцать дневных секций одного веса подряд («Характеристики», «Підходить для», «Сумісність з авто», «Що входить у монтаж», «Доставка й оплата», «Документи», «Разом працює краще», «Аксесуари», «Відгуки та питання», «Недавно переглянуті») — та же болезнь «набора частей», что была у главной до пяти актов. Галерея — одно фото и три пунктирные рамки «[ФОТО 2…4]», хотя у карточки того же товара в листинге уже 5 иллюстративных кадров (SPEC-002 §3.10).

- **Галерея товара = набор кадров карточки.** Главное фото + лента миниатюр из `productFrames(slug)` (те же 5 кадров, метка «Ілюстративне фото» на каждом); фото замовника (`images`, Q-6) заменяют набор целиком. Большой кадр — `<picture>` с `priority` (LCP), листание — тот же `Carousel` Motion+ на `client:intent` (D-069): до первого касания работает только серверный HTML, миниатюры — ссылки-якоря на кадры. Пунктирные рамки «[ФОТО N]» убираются, пока есть иллюстрации (D-031 не нарушается: метка «Ілюстративне фото» и строка CREDITS остаются).
- **Блок покупки прилипает** на ≥ 960 px (`position: sticky`, `top: header-h + space-m`) рядом с галереей и «Головне», пока прокручиваются характеристики; на телефоне — без изменений, плюс нижняя плашка «Ціна · До кошика / Розрахувати» после ухода блока покупки из кадра (`inView`, без анимации раскладки).
- **Ритм: три полосы вместо одиннадцати секций.** (1) «Головне + Характеристики» — одна секция, таблица характеристик в две колонки на 1440; (2) «Підходить для · Сумісність з авто · Що входить у монтаж · Доставка й оплата» — аккордеон `<details>` с `animateLayout` как FAQ главной (первый пункт открыт); (3) «Разом працює краще» — ряд-витрина на `Carousel` как хиты главной (компактные карточки, `gallery={false}`), «Аксесуари», «Документи», «Відгуки та питання» — одна полоса «Ще про товар» с плашками-плейсхолдерами в два столбца. Ночь — только порог и подвал (D-067), «Недавно переглянуті» остаются последними.
- **Без изменений:** состав данных, расчёт «з монтажем», совместимость с авто (§3.3), аналитика, JSON-LD, адреса.

## 4. Поведение и состояния
- Переключатель по умолчанию — «З монтажем під ключ» (H-002: цена под ключ на виду); выбор сохраняется для добавления в корзину.
- «До кошика»: счётчик в шапке растёт, кнопка на 1,6 с — «Додано ✓», ссылка «Перейти до кошика».
- Товар `sale_mode: quote` в корзину не попадает: только «Розрахувати».
- Без JS: все блоки и тексты в HTML; переключатель показывает обе цены списком; совместимость — таблица всех авто из `cars.json` с результатом; галерея — фото подряд.

## 5. Доступность
- Переключатель — радиогруппа «Тільки обладнання / З монтажем під ключ»; изменение цены — `aria-live="polite"`.
- Галерея: у фото `alt` из данных; увеличение — `<dialog>` с кнопкой закрытия, Esc, возврат фокуса.
- Таблица характеристик — `<table>` с `<th scope="row">`.
- Липкая панель не перекрывает фокусируемые элементы (отступ снизу страницы).
