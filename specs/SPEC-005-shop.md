## 1. Цель
Покупка AC-станции, панелей, инвертора или домашней батареи от главной до «Дякуємо» — не больше 6 шагов, без регистрации (ТЗ §6.8, §14). Сравнение до 4 товаров и поиск по названию, артикулу и разъёму с подсказками и опечатками (ТЗ §6.9, §10.1).

## 2. Источники
- ТЗ §6.8 (корзина: «з монтажем» по позиции, промокод, итог, аксессуары; оформление в 1 странице, 3 шага; гостевой заказ; «Дякуємо» с номером и шагами), §6.9 (сравнение до 4, «тільки відмінності», поиск с подсказками), §10.1 (оплата, доставка, недавно просмотренные, поиск с опечатками), §10.4 (`begin_checkout`, `purchase`), §14 (≤ 6 шагов; тестовая оплата — этап разработки).
- Инструкция 02 §2 (заглушки оплаты и Новой Почты с пометкой `TODO: integration`).
- Решения: D-013, D-026 п. 10 (ключи, событие), D-031.

## 3. Контракт

### 3.1. Хранилище (`src/lib/cart.ts`, `compare.ts`, `recent.ts`)
| Модуль | API | Ключ |
|---|---|---|
| Корзина | `items()`, `add(slug, turnkey)` (уже есть), `setQty(slug, turnkey, qty)`, `setTurnkey(slug, from, to)`, `remove(slug, turnkey)`, `clear()`, `totals(products)` | `etsgrid:cart:v1` |
| Сравнение | `list()`, `toggle`, `has` (уже есть), `remove(slug)`, `clear()`; лимит 4 | `etsgrid:compare:v1` |
| Недавно просмотренные | `push(slug)`, `list(n)`; до 8, без дублей | `etsgrid:recent:v1` (новый, ревизия SPEC-001) |

Каждое изменение корзины шлёт `etsgrid:cart-change`; сравнения — `etsgrid:compare-change` (новое событие).

**Итоги** `totals(items, products)`: `equipment` (сумма `price_equipment × qty`), `installation` (сумма `(price_turnkey_from − price_equipment) × qty` для позиций с монтажом), `total`; есть ли демо-цены → метка «демо-ціна».

### 3.2. `/koshyk/` — корзина
- Позиция: фото (или рамка), название-ссылка, переключатель «з монтажем» (если у товара есть обе цены), количество (−/+ и поле, 1–99), цена позиции, «Видалити».
- Итог: обладнання, монтаж, разом; «демо-ціна» при демо-ценах; кнопка «Оформити замовлення».
- Промокод: поле и кнопка видимы, неактивны, пометка «промокоди зʼявляться в бойовій версії» (D-031).
- «Додайте до замовлення»: аксессуары для товаров корзины — `related[]` (пусто → плашка «[АКСЕСУАРИ]») и адаптер `cable-gbt-type2` для станций с Type 2.
- Пусто: «Кошик порожній» + 4 плитки уровней + «Недавно переглянуті».
- Без JS: «Кошик працює з увімкненим JavaScript» + ссылки на уровни.

### 3.3. `/oformlennya/` — оформление, 1 страница, 3 шага
| Шаг | Поля | Заглушки |
|---|---|---|
| 1. Контакти | імʼя (обязательно), телефон (+380, SPEC-009 `normalizePhone`), email (необязательно) | — |
| 2. Доставка | Нова Пошта: відділення / поштомат / курʼєр (місто, номер відділення або адреса — текстом); «Доставка + монтаж» (адреса); самовивіз `[АДРЕСА]` | `TODO: integration` — поиск отделений Новой Почты, расчёт стоимости |
| 3. Оплата | онлайн-картою; частинами Monobank / ПриватБанк; накладений платіж; рахунок для юрособи (ЄДРПОУ, назва) | `TODO: integration` — платёжный провайдер; карточных полей нет |

- Справа (снизу на mobile) — состав заказа и итог из корзины.
- «Підтвердити замовлення» → проверка → заказ в `console.info('[order]', …)` (контракт §3.5) → `purchase` → корзина очищается → `/dyakuyemo/?type=order&id=ETS-ГГГГММДД-XXXX`.
- `begin_checkout` при открытии страницы с непустой корзиной; пустая корзина → «Кошик порожній» и ссылка назад.

### 3.4. `/dyakuyemo/` — «Дякуємо»
- `type=order`: «Замовлення № {id} прийнято», шаги: «менеджер підтвердить протягом [N] хвилин», оплата по выбранному способу, доставка.
- `type=lead`: текст из SPEC-009.
- Без параметров: общее «Дякуємо!» + ссылки.
- В адресе — только тип и номер, без персональных данных. Пометка в мокапе: «Демо: замовлення нікуди не надсилається».

### 3.5. Заказ (контракт для CRM)
`{ type: "order", id, created_at, customer: { name, phone, email }, delivery: { method, city, branch, address }, payment: { method, company? }, items: [{ slug, qty, turnkey, price_equipment, price_turnkey_from, demo }], totals: { equipment, installation, total }, source_url, utm }`.

### 3.6. `/porivnyannya/` — сравнение
- До 4 товаров колонками; строки — объединение характеристик (подписи — словарь SPEC-003), цена, наличие, кнопка по `sale_mode`, «Прибрати».
- «Тільки відмінності» — скрывает строки, где у всех одинаково (состояние интерфейса, не данные — D-031 не нарушается).
- Товары разных уровней: группы строк по уровням, пустые ячейки — «—».
- Пусто: «Додайте товари кнопкою «Порівняти» в каталозі».
- Mobile: горизонтальная прокрутка таблицы внутри своего блока с закреплённой первой колонкой.

### 3.7. Поиск
- `src/lib/search.ts`: индекс на сборке (название, slug, бренд без плейсхолдеров, подписи разъёмов, категория, уровень); нормализация (регистр, `ʼ`/`'`, `і/и`, `є/е`, транслит латиницей «gbt» = «GB/T»); опечатки — расстояние Левенштейна ≤ 1 для слов от 4 букв.
- `/poshuk/?q=` — результаты карточками `ProductCard`, «Знайдено: N», пусто — «Нічого не знайшли» + подсказка и плитки уровней.
- Подсказки: в поле поиска шапки после 2 символов — до 6 товаров и категорий; стрелки, Enter, Esc (паттерн WAI-ARIA Combobox). Ревизия SPEC-001: шапка получает скрипт подсказок.
- Без JS: форма отправляется на `/poshuk/?q=…`; на статическом сайте результатов без JS нет — видимая строка «Пошук працює з увімкненим JavaScript» (в боевом сайте — сервер).

### 3.8. Миниатюры и плитки в языке витрины (ревизия 1, D-071)
**Осмотр 15.10** (`research/shop-review/*.png`): в корзине, сравнении и «Недавно переглянуті» вместо фото — серые квадраты с подписью уровня («Зарядні станції»), хотя у тех же товаров в каталоге есть иллюстрации; плитки уровней в пустой корзине — текстовые карточки без иконок и огоньков, в отличие от плиток героя и главного фильтра.

- **Миниатюра товара везде одна:** первый кадр `productFrames(slug)` (или фото замовника), 1:1, `rounded.m`, метка «Ілюстративне фото» — маленькой точкой-подписью под миниатюрой (на 64–96 px метка на кадре нечитаема). Общий компонент `ProductThumb.astro` (`src/components/catalog/`) для корзины, оформления (сводка), сравнения, «Недавно переглянуті», подсказок поиска.
- **Плитки уровней пустой корзины и «Дякуємо»** — грамматика плиток героя (иконка уровня, название, «від … ₴», огонёк `::after`), на дне.
- **Без изменений:** хранилище, расчёты, формы, события, адреса.

## 4. Поведение и состояния
- Изменения корзины сразу пересчитывают итог и счётчик в шапке (`etsgrid:cart-change`).
- Количество вне 1–99 прижимается к границе.
- Товар, исчезнувший из каталога, но оставшийся в корзине, — строка «Товар більше недоступний» и «Видалити».
- Ошибки формы оформления — как в SPEC-009 (сводка, фокус).

## 5. Доступность
- Корзина — таблица или список с подписанными кнопками («Збільшити кількість: ETS Home 7»); итог — `aria-live="polite"`.
- Шаги оформления — `<fieldset>` с `<legend>`; выбор способа — радиогруппы.
- Сравнение — `<table>` с `<th scope>`; «Тільки відмінності» — переключатель с `aria-pressed`.
- Подсказки поиска — WAI-ARIA Combobox (`aria-expanded`, `aria-activedescendant`).

## 6. Мокап → боевой
| Что | В мокапе | В боевом сайте |
|---|---|---|
| Заказ | `console.info` + «Дякуємо» | CRM, письмо и SMS / Viber клиенту, Telegram менеджеру |
| Оплата | выбор способа без полей карты | LiqPay / WayForPay / Monobank (выбирает заказчик), «Покупка частинами», счёт PDF |
| Доставка | текстовые поля | API Новой Почты, зоны собственной доставки |
| Промокоды | поле неактивно | правила промокодов в CMS |
| Поиск | индекс на клиенте | серверный поиск |
