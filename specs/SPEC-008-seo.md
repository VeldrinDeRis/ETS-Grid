## 3. Контракт

### 3.1. Шаблоны title и description (`src/lib/seo.ts`)
| Тип страницы | title (≤ 60 знаков) | description (120–160 знаков) |
|---|---|---|
| Главная | из `home-content.json` (H1 активного варианта) + « — ETS GRID» | текст главной |
| Уровень | «{Рівень} під ключ — ціни, монтаж · ETS GRID» | ценность уровня + «Київ і вся Україна» |
| Листинг | «{Категорія}: {рівень} — ціни · ETS GRID» | `hint` + «з монтажем, доставка по Україні» |
| ЧПУ-страница | `h1` пресета + « · ETS GRID» | `description` пресета |
| Товар | «{Назва} — ціна {від …} · ETS GRID» | 2 ключевые характеристики + «з монтажем під ключ» |
| Система, услуга, контент | «{H1} · ETS GRID» | вступ страницы |

Обрезка по границе слова; уникальность title и description по сайту — проверяется тестом.

### 3.2. Микроразметка JSON-LD
| Где | Тип | Поля и правило «ничего не выдумывать» |
|---|---|---|
| Все страницы | `Organization` | `name: "ETS GRID"`, `url`, `areaServed: "UA"`; `telephone`, `email`, `logo` — только когда в данных нет плейсхолдера (сейчас — не выводятся) |
| `/kontakty/` | `LocalBusiness` | то же правило; адрес — после данных заказчика |
| Все страницы ниже главной | `BreadcrumbList` | из крошек `BaseLayout` |
| Товар | `Product` + `Offer` | `name`, `sku` (после данных; сейчас нет), `brand` (не плейсхолдер), `image`, `offers.price` = цена оборудования или «під ключ від» (`priceSpecification` для «від»), `priceCurrency: "UAH"`, `availability` из `stock`; `AggregateRating` — **не выводится**, пока нет реальных отзывов |
| Страницы с FAQ (уровни, главная, товар) | `FAQPage` | вопросы и ответы — те же тексты, что в HTML |
| Листинг, ЧПУ | `ItemList` | товары в порядке выдачи |
| Гид | `Article` | заголовок, дата — `[ДАТА]` не выводится до данных |

### 3.3. Индексация
- `noindex, follow`: `/koshyk/`, `/oformlennya/`, `/dyakuyemo/`, `/porivnyannya/`, `/poshuk/`, 404.
- `canonical`: на себя у всех индексируемых; листинг с параметрами фильтров — canonical на чистый адрес (в статике всегда так); ЧПУ-страницы — на себя (SPEC-002).
- `robots.txt`: `Disallow` для служебных адресов, ссылка на sitemap. Правила — как для боевого сайта: мокап не публикуется, отдельный запрет индексации ему не нужен.
- `sitemap`: только индексируемые страницы (фильтр в `@astrojs/sitemap`).
- `hreflang`: `uk` и `x-default` на себя (готовность к другим языкам, ТЗ §11).
- Open Graph: `og:title`, `og:description`, `og:type` (`product` для товаров), `og:url`, `og:image` — фото товара или `og-default.png` после SPEC-010; до этого — без `og:image` (не выдумываем картинку). `og:locale = uk_UA`.

| Что | В мокапе | В боевом сайте |

| Домен | `ets-grid.test` (Q-7) | домен заказчика |

- [ ] **AC-05** · `FAQPage` совпадает по текстам с FAQ в HTML · `build`
- [ ] **AC-06** · `robots.txt` и `sitemap-index.xml` собраны; `hreflang` и Open Graph на всех индексируемых страницах · `build`

## 6. Решения в этой спецификации
Шаблоны title и description; правило «в JSON-LD нет плейсхолдеров»: неизвестные поля не выводятся; без `AggregateRating` до реальных отзывов; без `og:image` до SPEC-010; `robots.txt` как для боевого сайта.
